# 🧮 Math Game

A simple console-based Math game built using C++.  
Play the game to solve math questions through multiple rounds and difficulties with colored game with colored results and final statistics.

---

## 🚀 Features

- Multiple game rounds
- Multiple game difficulties
- Random computer choices
- Round winner detection
- Final game summary
- Colored console feedback
- Replay system

---

## 🛠️ Technologies

- C++
- Structs
- Enums
- Functions
- Random Number Generation
